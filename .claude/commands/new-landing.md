---

Поднять новый лендинг. Аргумент: `$ARGUMENTS` (домен и/или краткий бриф оффера; если пусто — спроси домен, оффер, целевые ключи, контакты/оплату).

Пайплайн (строго по порядку, не пропускать гейты):

1. **Конфиг.** Создай `sites/<domain>.json`: **уникальный фантик-бренд под этот домен (НЕ «Xor»** — модель «фантик на домен», см. CLAUDE.md), домен, оффер, целевые ключевики, тарифы (со `slug`), `checkout` (провайдер/apiBase), id аналитики, ссылки на юр-страницы. Оплата и выдача ключа — на сайте (`/buy/<slug>` → `/success`), CTA тарифов ведут на on-site оформление. Если шаблона Astro ещё нет — сначала подними каркас через агента `astro-landing-builder`.

2. **Копирайтинг.** Агент `conversion-copywriter` пишет тексты (hero, выгоды, доверие, тарифы, FAQ, CTA) по лестнице прогрева под этот оффер и ключи.

3. **⚖️ Юр-гейт (блокирующий).** Агент `legal-compliance-rf` проверяет ВСЕ тексты по №281-ФЗ. FAIL → вернуть копирайтеру на правку, повторить. Без PASS дальше не идём. Проверь и наличие оферты/политики/реквизитов/согласия ПДн.

4. **Вёрстка.** Агент `astro-landing-builder` собирает лендинг из компонентов по конфигу. Минимум JS, критический CSS инлайн.

5. **SEO.** Агент `seo-optimizer`: title/meta/OG, schema.org (Organization/Service/FAQPage), h1/иерархия, ключи без переспама, sitemap/robots.

6. **Сборка + перф.** `npx astro build --site https://<domain>`, затем агент `web-perf-auditor` (Core Web Vitals). FAIL по CWV → чинить.

7. **Итог.** Кратко отчитайся: домен, вердикт юр-гейта, ключи, метрики CWV, что осталось руками (подключить платёжного провайдера + бэкенд выдачи ключа, реальные реквизиты + чек 54-ФЗ, маркировка рекламы/erid, деплой).

Запускай специализированных агентов для каждого шага, не делай всё сам в одном контексте.
