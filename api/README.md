# Phantom Lendings API

Тонкий общий сервис-обёртка над **Lava.top** — один на все домены-лендинги. Держит секрет Lava server-side, создаёт счёт, отдаёт ключ Xor после оплаты. Лендинги (статика) ходят сюда через `fetch`.

**Стек:** Node + Express + встроенный `node:sqlite` (без нативной сборки).

## Контракт (его ждёт фронт лендинга)
| Метод | Назначение | Тело / параметры | Ответ |
|------|-----------|------------------|-------|
| `POST /pay` | Создать счёт | `{ plan, email, method, attr }` | `{ url, order }` — редирект на checkout Lava |
| `GET /key?order=<id>` | Забрать ключ после оплаты | — | `{ key }` или `{}` (ещё не выдан) |
| `POST /webhook/lava` | Webhook Lava: оплата → выдача ключа | сырое тело + подпись | `200` |
| `GET /health` | Проверка | — | `{ ok, demo }` |

`success_url` для Lava строится на домене, с которого пришёл запрос (заголовок `Origin`) → пользователь возвращается на свой лендинг `/success/?order=<id>`.

## Запуск
```bash
npm install
cp .env.example .env        # заполни LAVA_* и (опц.) ALLOWED_ORIGINS
npm run seed-keys           # наполнить пул ключей (демо) — или: npm run seed-keys KEY1 KEY2 ...
npm start                   # http://localhost:8787
```

## Демо без Lava
Если `LAVA_API_KEY` пуст — сервис работает в демо-режиме: `POST /pay` сразу помечает заказ оплаченным и выдаёт ключ из пула. Прогнать контракт:
```bash
npm run seed-keys
npm run smoke               # дёрнет /health, /pay, /key и распечатает результат
```

## Что доделать перед боем (TODO в коде)
1. **`src/lava.mjs`** — сверить с актуальной документацией Lava.top: endpoint создания счёта, имена полей, заголовок авторизации, **алгоритм подписи webhook**.

3. **`products.json`** — проставить `lavaProductId` для каждого тарифа (товары из кабинета Lava.top).
4. Дублирование ключа на **e-mail** после оплаты (как обещано на `/success`).
5. **`ALLOWED_ORIGINS`** — ограничить список доменов (или оставить пусто = любой Origin).

## Связка с лендингом
В конфиге домена `../sites/<domain>.json` укажи `checkout.apiBase` = URL этого сервиса. Лендинг шлёт только `plan` (slug) — соответствие slug → товар Lava живёт здесь, в `products.json`.

## Деплой
Любой Node-хост рядом с бэкендом Xor (тот же VPS, что и бот — удобно для выдачи ключей). Вынеси `data.db` на постоянный диск; HTTPS — через реверс-прокси (nginx/caddy). Вебхук Lava укажи на `https://<api-домен>/webhook/lava`.
